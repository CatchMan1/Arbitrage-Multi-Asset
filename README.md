# ETF PCA 统计套利

日频、多 ETF 的 PCA 残差均值回归实验。流程为：**逐行业导出数据 → 每个行业用训练集选参数 → 验证集综合评分选行业 → 固定行业和参数查看测试表现**。实现使用 pandas / numpy，计算按中文 Notebook 顺序展开，没有额外策略框架或函数封装。

本说明根据 **2026-11-08 当前保存的 CSV / JSON 结果**整理。本次只清理目录、核对与汇总既有结果，没有重新运行网格或回测。当前验证选中的行业为 **周期材料**，共 **27 只 ETF**；测试累计收益 **6.3029%**，年化夏普 **0.7528**，最大回撤 **-8.3214%**。这些数字属于下述简化成交与计费假设下的历史结果。

## 模型与评分

每个滚动窗口对 ETF 对数收益去均值并除以标准差，通过 SVD 提取前 k 个主成分，从收益中减去重构部分得到残差。残差累计为 X，拟合 `X_t = a + b × X_(t-1) + e_t`。仅对 `0 < b < 1` 计算：

```text
m = a / (1 - b)
sigma_eq = std(e, ddof=2) / sqrt(1 - b²)
s = (X末值 - m) / sigma_eq
half_life = -log(2) / log(b)
```

半衰期在 5～60 日时允许主动信号。s 低于负开仓线做多，高于正开仓线做空；进入 `abs(s) < s_close` 的平仓带或模型失效时退出，否则延续方向。方向经过 PCA 因子对冲、波动率调整，总绝对权重在非空仓日归一为 1；没有主动信号的 ETF 也可能承担对冲仓位。

当前已保存的网格为：

| 参数 | 候选值 |
|---|---|
| window | 40、60、80、100、120、150、180、200、252 |
| k | 1～15，且小于行业入选 ETF 数和窗口长度 |
| s_open、s_close | 0.1、0.25、0.5、0.75、1、1.25、1.5、1.75、2、2.25、2.5 |
| 阈值限制 | s_close < s_open |
| 费率 | 0.0005，即单边 5bp |

完整结果共有 **62,370 组参数组合**，其中 **52,310 组可评分**，其余 **10,060 组**因指标非有限而不评分，仍保留在表内。当前没有额外的最低持仓天数门槛。

训练时在**每个行业内部**对期末净值、年化夏普、负数最大回撤做 Min-Max 归一化，再等权相加：

```text
单项得分 = (指标 - 该指标最小值) / (该指标最大值 - 该指标最小值)
综合得分 = 净值得分 + 夏普得分 + 回撤得分
```

三个指标都越大越好：负数回撤越接近 0 越好。指标全相同时统一给 0.5 分；任一指标为 NaN 或无穷大则不评分。训练参数按综合得分选出后，在验证集固定不变；验证阶段再在行业候选间重新归一化、相加，选择综合得分最高的行业。训练分数不能直接跨行业比较，测试指标不参与任何选择；并列保留原有顺序。

## 回测口径与解释边界

```python
weights = signal_weights.shift(1).loc[start:end]
asset_returns = np.expm1(returns.loc[weights.index])
turnover = weights.diff().fillna(weights).abs().sum(axis=1)
strategy_ret = (weights * asset_returns).sum(axis=1) - turnover * fee
net_value = 1 + strategy_ret.cumsum()
```

- 信号和权重先保存 CSV，再读取回测。收益按区间终点归属日期；对数收益先还原为简单收益。
- 采用固定初始资金加法累计，不是复利。净值不能把三段独立账户直接当作连续投资账户拼接解释。
- 换手按目标权重变化估算，包含首次建仓；不计价格漂移引起的额外再平衡。基准是同批 ETF 的每日等权、无费用、加法累计组合，其多头市场暴露与 PCA 多空组合不同。
- 夏普使用日盈亏、总体标准差 `ddof=0`、无风险利率 0 和 252 日年化；回撤为 `nav / nav.cummax() - 1`，包含初始净值 1。
- 沿用信号日收盘瞬时决策成交的理想化假设。行业选择使用验证末日收盘信息，测试首日包含该收盘至下一交易日收盘的收益，也依赖这一假设；未模拟券源、保证金、借券费用、点差、滑点或冲击成本。
- 数据保持原样，没有重新核对或修复价格。当前输入包含较大的单日收益跳变，选中行业中也有接近 −0.7 的单日对数收益记录。其经济含义和价格处理会影响结论。其他行业的部分训练明细也有极端单日收益，Min-Max 评分对这类极端值敏感。
- 训练用于选参，验证用于选行业，这两段都是选择过程回看。已有历史区间曾被查看过，重新划分不能使其变成全新未知样本。
